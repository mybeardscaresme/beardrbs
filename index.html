BeardRBS

Personal Health Analytics

BeardRBS is a private, noncommercial personal health analytics project that uses the Oura API to access health and wellness data with the account owner's authorization.

The purpose of this project is to examine historical trends in sleep, activity, recovery, heart rate, and other available wellness measurements.

This application is intended for personal use. Health information is processed locally and is not published on this website.
